## HavaHavai Chatbot

HavaHavai is an AI chatbot designed to fetch details about flight tickets and trips using a Retrieval Augmented Generation (RAG) approach. It leverages ChromaDB for efficient data retrieval and integrates a custom AI engine to generate conversational responses.

The application is built using Flask and has been updated to include enhanced security configurations (e.g., the secret key is now set to "HavaHavai-indigo").

### Key Features

- **RAG Integration:** Retrieves relevant data based on user input.
- **Markdown Support:** Converts AI responses from markdown to HTML for better presentation.
- **Flask-Based:** Uses Flask to handle web routing and API calls.
